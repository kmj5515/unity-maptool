## 1. 준비

### 창 열기
메뉴 **Tools > Map Tool > Map Tool 창**을 엽니다. 씬뷰 옆에 붙여 두면 편합니다.

<!-- 스크린샷: Map Tool 창 전체 (맵이 열린 상태) -->

### 새 맵 만들기
1. 창 맨 위 **맵** 칸이 비어 있으면 "편집할 맵 에셋을 고르거나 새로 만드세요."가 보입니다.
2. **새 맵 크기 (X, 층, Z)**를 정합니다. 기본은 20 × 4 × 20 칸(한 칸 = 1m)입니다.
3. **새 맵 만들기...**를 누르고 저장 위치를 고르면 바로 열립니다.

이미 있는 맵은 **맵** 칸에 끌어다 놓거나, 맵 에셋을 선택하고 인스펙터의 **Map Tool 창에서 열기**를 누릅니다.

> 맵을 열었는데 "현재 씬에 이 맵의 오브젝트가 없습니다."가 보이면 **현재 씬에 맵 표시**를 누르세요. 씬에 `[MapTool] 맵이름` 오브젝트가 생기고, 그 아래에 맵이 그려집니다. 맵은 씬마다 따로 표시해야 합니다.

### 놓을 물건(오브젝트 정의) 등록
맵에 놓는 물건 하나하나는 **오브젝트 정의** 에셋입니다. 프로젝트 어디에 두어도 자동으로 팔레트에 나타나므로, 따로 등록할 필요는 없습니다.

- 만들기: Project 창 우클릭 → **Create > Map Tool > Object Definition**
- 연습용: **Tools > Map Tool > 샘플 오브젝트 생성**을 누르면 상자·가구·벽 등 10종이 `Assets/MapToolSamples`에 생깁니다. 여러 번 눌러도 중복으로 생기지 않습니다.

정의 에셋에서 정하는 것:

| 항목 | 설명 |
|---|---|
| ID | 맵이 이 물건을 기억하는 이름. 비우면 에셋 이름을 씁니다. **배치한 뒤에 바꾸면 이미 놓인 것들이 끊깁니다.** |
| 종류 | **칸 오브젝트**: 칸에 맞춰 놓이고 칸을 차지합니다(건물·가구·울타리). **장식**: 브러시로 흩뿌리고 칸을 차지하지 않습니다(풀·꽃·돌). |
| 점유 크기 (X, 층, Z) | 칸 오브젝트가 차지하는 칸 수. 장식은 쓰지 않습니다. |
| 프리팹 | 씬에 보일 모델. 비우면 회색 상자로 보입니다. |
| 카테고리 | 팔레트의 탭 이름. 기본은 "기타". |

> 프리팹 피벗은 **차지하는 영역의 바닥 중심**, 정면은 **-Z**로 맞춰 두면 칸에 딱 맞게 놓입니다.

칸 오브젝트의 인스펙터에는 "바닥 오브젝트" 또는 "막는 오브젝트"라는 판정이 함께 나옵니다. 높이가 0.3m 이하인 길·바닥 타일은 바닥으로 보고, 그 위에 스폰을 두어도 경고하지 않습니다.

## 2. 오브젝트 배치

창 위쪽의 모드 막대 `끄기 | 선택 | 배치 | 브러시 | 존 | 스폰`에서 작업을 고릅니다. 모드는 마우스로만 바꿉니다.

### 놓기
1. 팔레트에서 물건을 클릭합니다. 자동으로 **배치** 모드가 됩니다.
   - 위쪽 탭으로 카테고리를, 검색 칸으로 이름·ID를 거를 수 있습니다.
2. 씬뷰에 마우스를 올리면 반투명 미리보기(고스트)가 따라옵니다.
   - **초록**: 놓을 수 있음
   - **빨강**: 놓을 수 없음 (맵 밖이거나 다른 물건과 겹침)
3. **R**로 90°씩 돌리고, 클릭해서 놓습니다. 모드가 유지되므로 계속 클릭하면 연달아 놓입니다.
4. 다 놓았으면 **Esc**로 선택 모드로 돌아갑니다.

빨간 고스트 위에는 놓을 수 없는 이유가 빨간 글씨로 뜹니다. 예: `셀 (3, 0, 5)에 이미 'crate'이(가) 있습니다.`, `'table'이(가) 맵 밖으로 나갑니다.` 선택 모드에서 끌어 옮길 때, 스폰을 찍을 때, 존을 그릴 때도 같습니다.

<!-- 스크린샷: 초록 고스트 / 빨간 고스트 -->

### 층
**층 (Y)** 슬라이더가 지금 놓는 높이입니다. 2층에 놓으려면 슬라이더를 1로 올리세요(0이 1층). 격자도 그 높이에 그려집니다.

### 고르기·옮기기·돌리기·지우기 (선택 모드)
- **클릭**: 그 칸에 있는 물건을 고릅니다(노란 테두리). 지금 층에 있는 것만 잡힙니다.
- **드래그**: 옆으로 옮깁니다. 층은 그대로입니다. 놓을 수 없는 곳이면 빨갛게 보이고, 놓으면 원래 자리로 돌아갑니다.
- **R**: 돌리기 / **Delete**: 지우기 (창의 **회전 (R)**, **삭제 (Del)** 버튼도 같음)
- **Esc**: 선택 해제

> 한 번에 하나씩만 고를 수 있습니다. 여러 개 선택·복사·붙여넣기는 아직 없습니다.

### 되돌리기
**Ctrl+Z** 되돌리기, **Ctrl+Y**(또는 Ctrl+Shift+Z) 다시 실행. 창 위쪽 **되돌리기** / **다시 실행** 버튼도 같습니다.

### 저장
창 위쪽에 **저장 안 됨**이 보이면 **저장**을 누릅니다. 맵 에셋이 저장됩니다. 씬에 보이는 오브젝트는 **씬도 저장해야** 남습니다(Ctrl+S).

## 3. 장식 브러시

풀·꽃·돌처럼 칸과 상관없이 흩어 놓을 것을 그림 그리듯 뿌립니다. 정의 에셋의 종류가 **장식**인 것만 쓸 수 있습니다.

### 시작하기
1. 팔레트에서 장식을 클릭합니다. 자동으로 **브러시** 모드가 되고 **브러시 구성**에 담깁니다.
2. 여러 종류를 담으면 섞어서 뿌립니다. 각 줄의 슬라이더가 비율입니다(옆에 % 표시). 빼려면 **✕**.
3. 씬뷰에서 **드래그**하면 뿌려집니다.

<!-- 스크린샷: 브러시 원과 라벨 -->

### 씬뷰 조작

| 조작 | 효과 |
|---|---|
| 드래그 | 뿌리기 |
| Shift+드래그 | 반대로(지우기) |
| E | 그리기 ↔ 지우개 전환 |
| `[` / `]` | 브러시 반경 줄이기 / 늘리기 |
| Ctrl+휠 | 밀도 낮추기 / 높이기 |

브러시 원의 색:
- **초록**: 뿌릴 수 있음
- **빨강**: 필터에 걸림(경사가 너무 가파르거나 높이 제한 밖)
- **회색**: 브러시 구성이 비었음
- **주황 점선**: 지우개 — 지워질 장식은 빨간 점으로 표시됩니다

**한 번 드래그한 것은 Ctrl+Z 한 번으로 통째로 되돌아갑니다.** 같은 곳을 계속 문질러도 밀도 이상으로 쌓이지 않으니 마음 놓고 문지르세요.

### 설정

| 설정 | 뜻 |
|---|---|
| 반경 (m) | 브러시 크기 |
| 밀도 (개/㎡) | 1㎡에 몇 개까지 채울지 |
| 최소 간격 (m) | 장식끼리 이보다 가까이 붙지 않음. 0이면 검사 안 함 |
| 변형 › 랜덤 회전 (Y) | 방향을 제각각으로 |
| 변형 › 스케일 | 크기를 최소~최대 사이에서 무작위로 |
| 변형 › 지면 기울기 따르기 | 0 = 똑바로 서기, 1 = 비탈에 딱 붙기 |
| 필터 › 최대 경사 (°) | 이보다 가파른 곳에는 뿌리지 않음 |
| 필터 › 높이 제한 | 켜면 정한 높이 사이에만 뿌림 |
| 지우개 대상 | **구성에 담은 종류만** 또는 **모든 장식**. 칸 오브젝트는 지우지 않습니다 |

### 프리셋
자주 쓰는 조합(예: "길가 풀", "숲 바닥")은 프리셋으로 저장해 두세요.
- **새 프리셋으로 저장...**: 지금 구성과 설정을 새 에셋으로
- **프리셋** 칸에서 고르면 바로 불러옵니다
- 값을 고치면 **수정됨**이 뜹니다. **덮어쓰기**로 저장하거나 **다시 불러오기**로 되돌립니다

### 그 밖에
- 장식은 씬의 콜라이더 위에 뿌려집니다. 지형에 콜라이더가 없으면 맵 바닥 높이(평면)에 뿌려집니다.
- 장식이 많아 작업이 어지러우면 **씬에서 장식 숨기기**를 켜세요. 씬뷰에서만 숨기며 맵 데이터와 빌드에는 영향이 없습니다.

## 4. 사운드 존

> 오디오 패키지(`com.kmj5515.audio`)가 설치돼 있어야 프로필을 목록에서 고르고 씬에 실제 사운드 존이 생깁니다. 없으면 존 모드는 그대로 쓸 수 있지만 프로필 ID를 직접 입력하고, 씬에는 반영되지 않습니다(JSON에는 저장됨). 설치 방법은 [README](../README.md)를 보세요.

존은 "이 구역에 들어가면 이런 소리"를 정하는 상자입니다. 플레이 중 플레이어 위치에 따라 배경음과 울림이 바뀝니다.

### 그리기
1. **존** 모드로 바꿉니다.
2. 씬뷰 빈 곳을 **드래그**하면 새 존이 생깁니다("존 1", "존 2" …).
   - 높이는 기본으로 맵 전체 높이입니다. 낮게 만들려면 **새 상자: 맵 전체 높이**를 끄고 **새 상자 높이 (층)**을 정하세요.
3. 오른쪽 상세에서 **오디오 프로필**을 고릅니다. 없으면 **새로…**로 만듭니다.

<!-- 스크린샷: 존 상자와 면 핸들 -->

### 다듬기
- **모양이 네모가 아닐 때**: 존을 고른 뒤 **Shift+드래그**로 상자를 덧붙입니다. ㄱ자·ㄷ자 구역도 존 하나로 만들 수 있습니다.
- **크기 조절**: 고른 존의 면에 있는 작은 큐브(핸들)를 끌면 칸 단위로 늘고 줄어듭니다.
- **상자 하나 지우기**: 상세의 상자 목록에서 **×**. 마지막 상자는 지울 수 없고, 존 전체는 **존 삭제 (Del)**로 지웁니다.
- **겹친 존 고르기**: 겹친 곳을 다시 클릭하면 다음 존으로 넘어갑니다.

### 겹칠 때 어느 존이 이기나
**우선순위**가 높은 존이 이깁니다. 같으면 더 작은 존이 이깁니다. 예를 들어 "숲" 안에 "동굴 입구"를 작게 그리면 따로 숫자를 바꾸지 않아도 동굴 입구가 이깁니다.

### 프로필
- 프로필이 없는 존은 소리가 바뀌지 않습니다. 목록에 경고 아이콘이 붙습니다.
- **보기**: 프로젝트 창에서 그 프로필 에셋을 찾아 줍니다.
- 프로필 에셋의 이름을 바꾸거나 폴더를 옮겨도 연결은 유지됩니다.

목록의 존을 **더블클릭**하면 씬뷰가 그 존으로 이동합니다.

## 5. 플레이어 스폰

플레이를 누르면 플레이어가 설 자리입니다.

1. **스폰** 모드로 바꿉니다.
2. 씬뷰에서 칸을 **클릭**하면 스폰 지점이 생깁니다. **R**로 바라볼 방향을 돌립니다.
3. 처음 만든 지점이 자동으로 **★ 기본**이 됩니다. 다른 지점을 기본으로 하려면 목록에서 **☆**을 누르세요.

- 드래그로 옮기고, **Delete**로 지웁니다.
- **▶** (또는 상세의 **▶ 여기서 플레이**): 기본 스폰은 그대로 두고 **이 지점에서 바로 플레이**합니다. 특정 장소를 확인할 때 편합니다.
- 씬뷰에서 분홍 화살표가 기본 스폰, 청록이 나머지입니다. 화살표는 어느 모드에서나 보입니다.

> 건물이나 가구가 있는 칸에 스폰을 두면 "끼일 수 있습니다" 경고가 납니다. 길·바닥 타일처럼 낮은 것(0.3m 이하) 위는 괜찮습니다.

> "여기서 플레이"를 눌렀는데 "씬에 PlayerSpawner가 없어…"라는 창이 뜨면 **붙이고 플레이**를 누르세요. 플레이어 오브젝트에 필요한 컴포넌트를 붙여 줍니다(Ctrl+Z로 되돌릴 수 있음).

## 6. 검증과 빠른 수정

맵에 문제가 있으면 창 위쪽 버튼이 알려 줍니다. 편집할 때마다 자동으로 다시 검사합니다.

- `검증 ✓`: 문제 없음
- `검증 3 · 경고 2`: 오류 3개, 경고 2개 — 누르면 목록이 펼쳐집니다

**오류**(빨강)는 맵이 망가진 것이고, **경고**(노랑)는 동작은 하지만 의도와 다를 수 있는 것입니다.

<!-- 스크린샷: 검증 목록과 씬뷰 표시 -->

### 목록 쓰는 법
- **항목 클릭**: 씬뷰가 그 위치로 이동하고, 문제를 굵은 상자와 글씨로 보여 줍니다. 오브젝트·존·스폰이면 해당 모드로 바뀌고 그것이 선택됩니다.
- **줄 끝 버튼(삭제 등)**: 빠른 수정. 누르면 바로 고쳐지고, **Ctrl+Z**로 되돌릴 수 있습니다.

### 자주 보는 항목과 처리

| 메시지 (요약) | 뜻 | 빠른 수정 |
|---|---|---|
| …와 N칸 겹칩니다 | 두 물건이 같은 칸에 있음 | **삭제** (나중에 놓인 쪽) |
| 맵 범위를 벗어납니다 | 맵 크기를 줄였거나 밖에 놓임 | **삭제** |
| 정의를 찾을 수 없습니다 | 정의 에셋이 지워졌거나 ID가 바뀜 | **삭제** — 또는 정의를 되살리면 저절로 해결 |
| 프리팹이 없어 회색 상자로 보입니다 | 정의에 프리팹이 비어 있음 | **정의 보기** → 프리팹 지정 |
| 프로필이 지정되지 않아… | 존에 소리가 없음 | 항목 클릭 → 존 상세에서 프로필 고르기 |
| 프로필 '…'을(를) 찾을 수 없습니다 | 프로필 에셋이 지워짐 | **프로필 해제** 후 다시 고르기 |
| 상자 N번의 크기가 0입니다 | 존 상자가 납작해짐 | **상자 정리** |
| 스폰 지점이 없습니다 | 플레이 시작 위치 없음 | 스폰 모드에서 하나 찍기 |
| …끼일 수 있습니다 | 스폰이 물건 위에 있음 | 스폰을 옆 칸으로 끌기 |

> 프로필을 찾을 수 없다는 메시지에는 프로필 이름 대신 긴 영문·숫자(에셋 ID)가 보일 수 있습니다. 정상입니다.

## 7. JSON 내보내기·가져오기

맵을 사람이 읽을 수 있는 텍스트 파일로 주고받습니다. 백업, 다른 프로젝트로 옮기기, 버전 비교에 씁니다.

창 위쪽 **JSON** 메뉴:
- **JSON으로 내보내기...**: 지금 맵을 `.json` 파일로 저장합니다.
- **JSON으로 덮어쓰기...**: 고른 파일로 지금 맵을 통째로 바꿉니다. 바꾸기 전에 "지금 / 바뀐 뒤" 개수를 보여 주고 확인을 받습니다. **Ctrl+Z 한 번으로 이전 맵으로 돌아옵니다.**

맵을 열지 않은 상태에서는 **JSON에서 새 맵 만들기...**로 파일에서 새 맵 에셋을 만들 수 있습니다.

- 파일이 깨졌으면 "가져오기 실패" 창이 이유와 함께 뜨고, 맵은 바뀌지 않습니다.
- 이 프로젝트에 없는 물건이 들어 있으면 일단 가져온 뒤 "알 수 없는 오브젝트 N개"라고 알려 주고 검증 목록을 펼칩니다. 회색 상자로 자리만 차지하니, 정의를 만들어 주거나 빠른 수정으로 지우세요.

## 8. 단축키 한눈에 보기

단축키는 **씬뷰나 Map Tool 창을 클릭해 둔 상태**에서, 모드가 **끄기가 아닐 때** 동작합니다.

| 키 | 동작 | 쓰는 모드 |
|---|---|---|
| Ctrl+Z | 되돌리기 | 전부 |
| Ctrl+Y / Ctrl+Shift+Z | 다시 실행 | 전부 |
| R | 90° 회전 | 선택 · 배치 · 스폰 |
| Delete | 고른 것 지우기 | 선택 · 존 · 스폰 |
| Esc | 드래그 취소 → 배치 끝내기 → 선택 해제 | 전부 |
| E | 그리기 ↔ 지우개 | 브러시 |
| `[` / `]` | 반경 줄이기 / 늘리기 | 브러시 |
| Ctrl+휠 | 밀도 | 브러시 |
| Shift+드래그 | 브러시: 반대 동작 / 존: 상자 덧붙이기 | 브러시 · 존 |
| Alt+드래그 | 씬뷰 회전 (맵툴은 무시) | 전부 |

키를 바꾸고 싶으면 **Edit > Shortcuts**에서 "Map Tool" 항목을 고치면 됩니다.

## 9. 자주 막히는 상황

**씬뷰에서 맵 오브젝트를 클릭해도 선택되지 않아요.**
의도된 동작입니다. 맵툴이 만든 오브젝트는 실수로 건드리지 않도록 클릭 선택을 막아 두었습니다. 물건을 고르려면 Map Tool 창에서 **선택** 모드로 바꾼 뒤 클릭하세요.

**Hierarchy에서 맵 오브젝트를 직접 옮겼는데 원래대로 돌아갔어요.**
맵의 내용은 맵 에셋에 있고, 씬 오브젝트는 그것을 보여 주는 결과물입니다. 손으로 고친 것은 맵을 다시 열 때 맵 에셋 기준으로 되돌아갑니다. 옮기거나 돌리는 것은 Map Tool 창에서 하세요. 같은 이유로 `[MapTool] 맵이름` 아래에 다른 오브젝트를 넣지 마세요. 지워질 수 있습니다.

**고스트가 빨갛게 나와서 놓을 수가 없어요.**
고스트 위에 뜬 빨간 글씨가 이유입니다. 대부분 맵 밖이거나 이미 다른 물건이 있는 칸입니다. 층 슬라이더가 엉뚱한 층에 가 있지 않은지도 확인하세요.

**Ctrl+Z를 눌렀는데 맵이 안 돌아가요.**
다른 창(Hierarchy, Inspector 등)을 클릭해 둔 상태이거나 모드가 **끄기**면 Ctrl+Z가 유니티 기본 되돌리기로 갑니다. 씬뷰를 한 번 클릭하고 다시 누르거나, 창 위쪽 **되돌리기** 버튼을 쓰세요.

**되돌리기 기록이 사라졌어요.**
오브젝트 정의의 크기·종류·프리팹을 바꾸거나 맵 에셋이 다시 로드되면 맵툴이 새로 시작하면서 되돌리기 기록이 비워집니다. 큰 작업 전에는 **저장**하거나 **JSON으로 내보내기**로 백업해 두세요.

**선택 모드에서 2층 물건이 안 잡혀요.**
클릭은 **층 (Y)** 슬라이더의 층에서만 찾습니다. 슬라이더를 그 층으로 올리세요.

**장식이 허공이나 땅속에 뿌려져요.**
지형에 콜라이더가 없으면 맵 바닥 높이에 평평하게 뿌려집니다. 지형 오브젝트에 Mesh Collider를 붙이세요.

**브러시로 그려도 아무것도 안 나와요.**
브러시 원이 회색이면 구성이 비었습니다(팔레트에서 장식 클릭). 빨간색이면 필터에 걸린 것이니 **필터 › 최대 경사**나 **높이 제한**을 확인하세요. 밀도가 0인지도 보세요.

**존을 그렸는데 소리가 안 바뀌어요.**
존에 **오디오 프로필**이 지정되었는지 확인하세요(목록에 경고 아이콘). 다른 존과 겹친다면 **우선순위**를 올리세요.

**저장했는데 씬을 다시 열자 맵이 안 보여요.**
**저장**은 맵 에셋만 저장합니다. 씬도 저장(Ctrl+S)하거나, 창에서 **현재 씬에 맵 표시**를 누르면 다시 그려집니다.
